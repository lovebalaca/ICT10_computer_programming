# ICT 10 Sample Web Page

## About the Project

This is a sample webpage created for ICT 10 students using HTML and External CSS.

The project demonstrates how an HTML file can be connected to a separate CSS file.

## Project Files

* `index.html` – contains the structure and content of the webpage.
* `style.css` – contains the design and formatting of the webpage.
* `README.md` – contains information about the project.

## HTML and CSS Connection

The `index.html` file connects to `style.css` using:

```html
<link rel="stylesheet" href="style.css">
```

This code should be placed inside the `<head>` section of `index.html`.

## Technologies Used

* HTML5
* CSS3

## Editor

This project can be created using:

* SPCK Editor
* Notepad++
* Visual Studio Code

## Learning Objectives

Students will learn how to:

1. Create a basic HTML webpage.
2. Create an external CSS file.
3. Link HTML to CSS.
4. Apply CSS properties to HTML elements.
5. Create and style navigation buttons.
6. Preview a webpage in a browser.

## How to Run

Open `index.html` in a web browser to view the webpage.

Make sure that `index.html` and `style.css` are in the correct folder.
